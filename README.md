# End-to-end self driving model


---
This project is about exploring and implementing end-to-end architecture for self-driving car. 

The first part covers exploring the nuscenes dataset and understand how the dataset works and utilized by different modular end-to-end architecture.
I explored the dataset as a way to understand how they are to be used and also a way to learn logger and argparse module of python.
First exploration is about simple implementation and investigate nature of particular object and how to be used. Then extending that work by using argparse and logger with helper functions.
